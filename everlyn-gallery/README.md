# Everlyn Gallery

A beautiful community gallery for sharing AI-generated content created with Everlyn AI. Built with React + Vite.

## ✨ Features

- **📤 Upload System**: Easy drag-and-drop upload for images and videos
- **🎨 Beautiful Design**: Modern white and red themed interface
- **💬 Comment System**: Interactive commenting on all uploads
- **👤 User Attribution**: Twitter username integration for creators
- **📱 Responsive**: Works perfectly on all devices
- **💾 Local Storage**: Persistent data storage in browser

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone https://github.com/tomcode1000/everlyn-media-website.git
cd everlyn-media-website
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm run dev
```

4. Open [http://localhost:5173](http://localhost:5173) in your browser

## 🛠️ Built With

- **React 19** - UI framework
- **Vite** - Build tool and dev server
- **CSS3** - Styling with modern gradients and animations
- **LocalStorage** - Client-side data persistence

## 📁 Project Structure

```
src/
  components/
    Header.jsx          # App header with logo and upload button
    GalleryGrid.jsx     # Main gallery grid displaying uploads
    UploadModal.jsx     # Modal for uploading new content
    CommentSection.jsx  # Comment system for each upload
  App.jsx              # Main app component
  App.css              # Global styles and theme
  main.jsx             # Entry point
```

## 🎨 Features Overview

### Upload System
- Support for images (JPEG, PNG, GIF, WebP) and videos (MP4, WebM, OGG)
- File size validation (max 50MB)
- Twitter username collection
- Real-time preview

### Gallery Display
- Responsive grid layout
- Hover animations
- File type badges
- Upload date and creator attribution

### Comment System
- Add comments with Twitter username
- Toggle comments visibility
- Timestamps for all comments
- Clean, organized display
